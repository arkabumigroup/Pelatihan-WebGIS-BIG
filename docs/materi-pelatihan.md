# Materi Pelatihan WebGIS

Materi ini disusun sebagai panduan belajar WebGIS (Web Geographic Information System) secara bertahap, dari tingkat dasar sampai lanjutan. Penyampaiannya menekankan praktik langsung, sehingga peserta dapat mengulang setiap tahap secara mandiri.

Materi dibagi menurut **hari pelaksanaan**, dan di dalam tiap hari dibagi menjadi **praktik**. Setiap praktik memuat satu atau beberapa halaman, sesuai banyaknya modul pada praktik itu.

## Materi per Hari

[**Hari 1 - Dasar GIS, Web, dan Peta 2D**](hari-1/index.md)

Praktik 1 sampai 4. Teori dasar GIS dan alur kerja WebGIS, pengolahan data spasial di QGIS, dasar HTML/CSS/JavaScript dan Leaflet, pengenalan framework Next.js, serta penggunaan GitHub.

[**Hari 2 - Peta 3D, Basis Data Spasial, dan GeoServer**](hari-2/index.md)

Praktik 5 sampai 7. Peta 3D dengan CesiumJS, basis data PostgreSQL dan PostGIS, serta GeoServer sebagai layanan penyaji data spasial.

[**Hari 3 - Backend dan Autentikasi**](hari-3/index.md)

Praktik 8 sampai 10. Basis data cloud di Supabase, Prisma ORM dan API login, CRUD API pengguna, serta autentikasi NextAuth beserta hak aksesnya.

[**Hari 4 - Deployment Project**](hari-4/index.md)

Praktik 11. Pemindahan aplikasi ke server: konfigurasi proyek, Virtual Machine di Google Cloud, Docker, Nginx, Cloud Build, subdomain, dan HTTPS.
