# Modul 3 - Pengembangan Frontend : Peta Web 3D

## **Tujuan Modul**

Setelah menyelesaikan modul ini, peserta diharapkan mampu untuk memahami dan mengimplementasikan beberapa materi dasar perancangan dan pengembangan WebGIS 3D menggunakan CesiumJS dengan rincian sebagai berikut ini.

1. Mengintegrasikan library spasial web CesiumJS ke dalam Framework Next.js.
2. Mengkonfigurasi CesiumJS Viewer sebagai dasar untuk membangun tampilan peta WebGIS 3D.
3. Menampilkan dan mengelola aset model 3D pada lingkungan WebGIS menggunakan format data 3D yang sesuai.
4. Mengintegrasikan dan menampilkan 3D Tiles sebagai salah satu format untuk visualisasi data dan objek 3D.
5. Mengintegrasikan data terrain atau elevasi seperti DEM/DTM/DSM ke dalam peta 3D.
6. Mengintegrasikan dan menampilkan citra satelit atau peta dasar pada permukaan terrain melalui proses draping.
7. Mengatur kamera dan navigasi peta 3D menggunakan fungsi seperti flyTo, setView, serta pengaturan heading, pitch, dan roll.
8. Menampilkan dan menggabungkan data spasial 2D dan 3D dalam satu tampilan WebGIS.
9. Membuat interaksi pengguna pada peta 3D menggunakan Screen Space Event Handler, seperti interaksi klik dan hover.
10. Melakukan 3D Object Picking dan menampilkan informasi semantik objek melalui InfoBox atau tampilan informasi yang dikustomisasi.
