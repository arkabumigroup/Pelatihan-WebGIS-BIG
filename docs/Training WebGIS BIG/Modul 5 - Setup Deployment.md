# Modul 5 - Setup Deployment

## **Tujuan Modul**

Modul ini bertujuan memberikan pemahaman dan keterampilan kepada peserta dalam melakukan penyiapan infrastruktur cloud, penggelaran (deployment) aplikasi web NextJS menggunakan kualifikasi kontainer, serta konfigurasi otomatisasi dan keamanan domain. Peserta akan mempelajari alur kerja pembuatan layanan berbasis cloud, pengoperasian Docker pada server Virtual Machine, serta pengaturan integrasi CI/CD dan enkripsi SSL/HTTPS.

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

1. Membuat dan mengonfigurasi project serta layanan Virtual Machine (VM) pada Google Cloud Platform.
2. Melakukan deployment aplikasi NextJS ke server VM menggunakan Docker.
3. Mengonfigurasi build trigger untuk otomatisasi alur kerja deployment.
4. Menghubungkan domain kustom dan menerapkan sertifikat SSL agar aplikasi dapat diakses secara aman melalui protokol HTTPS.
