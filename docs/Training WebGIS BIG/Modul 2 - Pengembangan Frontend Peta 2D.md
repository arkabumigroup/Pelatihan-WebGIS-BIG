# Modul 2 - Pengembangan Frontend : Peta 2D

## **Tujuan Modul**

Setelah menyelasaikan modul ini, peserta diharapkan mampu untuk memahami dan mengimplementasikan beberapa materi dasar perancangan dan pengembangan WebGIS dengan rincian sebagai berikut ini.

1. Mengintegrasikan library spasial web Leaflet kedalam Framework Next.js.
2. Membuat webgis peta 2D yang interaktif.
3. Menambahkan serta mengelola beberapa layer data spasial dalam WebGIS.
4. Menampilkan informasi atribut data spasial dengan menggunakan popup pada tampilan WebGIS.
5. Membuat dan menampilkan legenda peta.
6. Menampilkan data spasial dalam berbagai format meliputi GeoJSON, KML serta Mapserver (WMS).
7. Menampilkan data raster dalam WebGIS.
8. Melakukan styling tampilan dan layer pada WebGIS dengan menggunakan JavaScript dan CSS.
9. Merancangan WebGIS dengan interaksi pengguna dengan mudah.
10. Mengintegrasikan data dari GeoServer kedalam WebGIS.
