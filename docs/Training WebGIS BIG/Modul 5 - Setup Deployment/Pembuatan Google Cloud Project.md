# Pembuatan Google Cloud Project

## **Pembuatan Google Cloud Project**

1. Search google cloud di google dan pilih [https://cloud.google.com/gcp](https://cloud.google.com/gcp)
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image.png)
    
2. Pilih Get started for free
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%201.png)
    
3. Pilih akun dan Country yang akan digunakan lalu klik Agree & continue
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%202.png)
    
4. Kemudian buat Contact Information kemudian Save
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%203.png)
    
    ![](Pembuatan%20Google%20Cloud%20Project/image1.png)
    
5. Setelah Organization dibuat akan muncul Tax Information, pilih Head Office kemudian masukan NIK di kolom NPWP kemudian Save
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%204.png)
    
6. Kemudian Isi Add Payment Method dengan memasukan detail Kartu Kredit
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%205.png)
    
7. Setelah memasukan informasi pembayaran menggunakan kartu kredit, akan muncul tampilan step 2 untuk mengkonfirmasi metode pembayaran yang akan digunakan, selanjutnya klik start free.
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%206.png)
    
8. Berikut ini merupakan tampilan awal yang dari Google Cloud yang akan digunakan oleh peserta.
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%207.png)
    
9. Buka kembali [https://cloud.google.com/gcp](https://cloud.google.com/gcp) karena sudah sudah daftar trial maka akan muncul Go to my console, klik dan halaman akan menuju dashboard project default
    
    ![image.png](Pembuatan%20Google%20Cloud%20Project/image%208.png)
    
    ![](Pembuatan%20Google%20Cloud%20Project/image10.png)
