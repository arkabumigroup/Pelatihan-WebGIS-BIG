# Modul Membuat VM Google Cloud

## **Membuat Virtual Machine (VM) Google Cloud**

1. Pada overview project klik Create VM
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image.png)
    
2. Setelah itu Enable Compute Engine API
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image%201.png)
    
3. Setelah Compute Engine enable di project, anda akan diarahkan ke halaman VM Creation Wizard. Pada bagian machine configuration buat konfigurasi seperti ini
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image%202.png)
    
    ![](Modul%20Membuat%20VM%20Google%20Cloud/image3.png)
    
4. Setelah itu pindah ke bagian OS dan Storage, change OS dengan klik Change, kemudian setup dengan konfigurasi berikut
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image%203.png)
    
    ![](Modul%20Membuat%20VM%20Google%20Cloud/image5.png)
    
5. Setelah itu ke bagian Networking centang Allow HTTP traffic dan Allow HTTPS traffic
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image%204.png)
    
6. Setelah itu ke bagian security dan ubah Access scopes menjadi Allow full access to Cloud APIs. Setelah itu klik Create di paling bawah untuk membuat VM
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image%205.png)
    
7. Jika sudah selesai berikut adalah tampilan VM yang sudah dibuat
    
    ![image.png](Modul%20Membuat%20VM%20Google%20Cloud/image%206.png)
