# Modul 4 - Basis data dan Konektivitas

## **Tujuan Modul**

Modul ini bertujuan memberikan pemahaman dan keterampilan kepada peserta dalam melakukan instalasi, konfigurasi, serta pengelolaan basis data spasial sebagai fondasi dalam pengembangan aplikasi WebGIS. Peserta akan mempelajari struktur data spasial, pembuatan basis data dan tabel, konektivitas antara aplikasi dengan basis data.

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

1. Melakukan instalasi dan konfigurasi basis data untuk kebutuhan pengolahan data spasial.
2. Memahami struktur tabel spasial serta tipe data geometri yang digunakan dalam basis data spasial.
3. Membuat dan mengelola basis data beserta tabel untuk menyimpan data spasial dan atribut.
4. Menghubungkan aplikasi web dengan basis data melalui mekanisme konektivitas basis data.
