# Modul 1 - Persiapan dan Konfigurasi

Persiapan dan konfigurasi dasar dalam merancang serta membangun aplikasi WebGIS. Mempersiapkan perangkat lunak yang diperlukan dan pengaturan ruang kerja di Visual Studio Code, instalasi framework Next.js, hingga pengelolaan sistem menggunakan Git dan GitHub untuk kebutuhan kolaborasi pengembangan.

## **Tujuan Modul**

- Peserta mampu menyiapkan folder proyek dan membukanya menggunakan *code editor* Visual Studio Code.
- Peserta dapat melakukan inisialisasi dan konfigurasi *framework* Next.js menggunakan perintah terminal (`npx create-next-app@latest`) serta menjalankannya di *localhost*.
- Peserta mampu membuat repositori baru di GitHub dan mengunggah proyek lokal ke repositori tersebut menggunakan perintah GitBash.
- Peserta dapat melakukan proses *cloning* (menyalin) proyek dari GitHub ke perangkat lokal, serta menginstal *library* yang dibutuhkan menggunakan NPM (`npm install`).
- Peserta memahami dan mampu mempraktikkan alur kerja pengiriman serta pengambilan pembaruan proyek (*version control*) menggunakan perintah dasar Git seperti `git pull`, `git add`, `git commit`, dan `git push`.
