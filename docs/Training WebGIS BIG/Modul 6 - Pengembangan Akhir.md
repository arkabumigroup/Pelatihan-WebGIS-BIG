# Modul 6 - Pengembangan Akhir

## **Tujuan Modul**

Modul ini bertujuan memberikan pemahaman dan keterampilan kepada peserta dalam mengintegrasikan backend ORM, manajemen otentikasi pengoperasian spatial server, serta publikasi data spasial berbasis web. Peserta akan mempelajari mekanisme akses data spasial dari PostgreSQL ke GeoServer, penginstalan GeoServer pada Virtual Machine, serta implementasi otentikasi aman menggunakan Prisma, NextAuth, dan access token.

Setelah menyelesaikan modul ini, peserta diharapkan mampu:

1. Mengonfigurasi Prisma ORM dan membangun endpoint API untuk sistem autentikasi login.
2. Melakukan instalasi dan konfigurasi GeoServer pada lingkungan Virtual Machine (VM).
3. Menghubungkan basis data PostgreSQL ke GeoServer sebagai Data Store serta mempublikasikan layer spasial (Publish Layer).
4. Mengimplementasikan sistem otentikasi dan otorisasi menggunakan NextAuth dan access token untuk mengamankan hak akses aplikasi.
